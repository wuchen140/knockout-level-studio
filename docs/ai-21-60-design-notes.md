# AI21–60 新关卡设计矩阵

设计日期：2026-09-07。逐关读取 `public/data/levels/prod-21.json` 至 `prod-60.json` 的物品、图鉴、四元数、平台与运动配置；本文件仅为新设计矩阵，不修改关卡 JSON 或索引。

## 建造口径

- 每关以同编号主线为直接参考，保留该关的**完整材料集合、平台数量、形状、中心、朝向、运动及障碍物配置**。本范围主线没有挡板、弹力柱、锤子，不额外添加。不是章节每关都强行使用新材料或新机关；例如 45、46、48 不含冰，55–59 不横移。
- 下表 P1/P2/P3 始终指源平台 `sequence`；“前”按负 Z 一侧描述。多台各自有底座、支撑链和可见入口，不用跨台横梁，不把前后台改为并排台。各台所用材料优先保持源分组的功能分工。
- 新件使用图鉴已有长度与造型；构造物理高度以 `profile.modelSize` 和旋转后包围盒为准，写回 `item.size` 仍用 `profile.size`。例如三格石材源尺寸 `[3,1,1]` 不是实际竖向高度 1。
- 数量带是设计约束，不是填充指标；计数均为物品总数，不含平台。移动次数先取源预算附近的建议值，验证后可微调 1–2 次；21 起逢 x4/x7 为困难，x0 为超难，其余普通。
- 一格宽支撑只承担其可解释的上方负载。横梁至少有两个端部落点，缺口上方必须用合法长件搭梁，禁止凭空悬挂“像素”。圆台以真实圆形/椭圆轮廓验底座，不能仅按外接矩形摆满角点。
- 弱点是优先试验入口，不预先承诺一击垮塌。纸箱、石材及长件可能需要先卸上层；每台都要测低层入口、上层卸载入口以及侧面非最优击打。

## 实施前重点校正

1. 源关卡在当前工作台静置预演有失稳的 23、56、59，沿用材料/平台教学，重新建立可解释的支撑，不能把源坐标当成合格物理基线。源 42、46 也存在包围盒交叠，重建时统一消除明显穿插。
2. 双平台 33/52 用同材但不同轮廓与弱层；54/59/60 用源关已有的材料分工差异。46/49/53 必须保持前后台与遮挡关系；每台分别记录预期入口和对照入口，不能只测其中一台。
3. 27/35/48 的三平台都要保留源前后与偏转布局。35 明确低压恢复，不把三台数量本身当作困难；27 是独立任务组困难；48 是折线视角变化。
4. 最近点/最大旋转半径的扫掠检查不能只检查静止首帧。52/60 相向运动时检查台缘与结构外缘；54 同向运动保留相位；33/49/60 负旋转轴和负速度都必须正确折算。
5. 当前 `src/physics/levelPhysics.js` 把平台设为固定矩形，尚未模拟台面移动、旋转、圆形边缘；静置/击打验证可用于支撑基础，但不能据此报告“动态通关通过”。动态包络须独立几何检查，完整时机难度需实际游戏复测。
6. 推荐先完成21–30结构与验证，再依次31–40、41–50、51–60。每20关复核轮廓重复、恢复关密度、多台差异和源预算偏离，不为达到数量带下限而补无意义填料。
